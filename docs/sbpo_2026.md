# Guia de adaptacao para o SBPO 2026

## Posicionamento do artigo

Nao vale a pena manter a narrativa de "Entrega 1, Entrega 2, Entrega 3". Para o SBPO, o texto fica melhor como uma contribuicao unica:

**proposta de uma ferramenta de apoio a decisao para um problema de atribuicao multiobjetivo, combinando GRASP/VNS para gerar alternativas eficientes e FITradeoff para apoiar a escolha final.**

## Titulo sugerido

Algumas opcoes de titulo:

1. `Uma Ferramenta GRASP/VNS com FITradeoff para Apoio a Decisao no Problema Multiobjetivo de Atribuicao de Tarefas`
2. `GRASP/VNS e FITradeoff para Otimizacao e Escolha de Solucoes no Problema Multiobjetivo de Atribuicao de Tarefas`
3. `Apoio a Decisao Multiobjetiva em Atribuicao de Tarefas: uma Ferramenta baseada em epsilon-restrito, GRASP/VNS e FITradeoff`

## Resumo base

Texto inicial para o resumo:

> Este trabalho propoe uma ferramenta de apoio a decisao para o problema multiobjetivo de atribuicao de tarefas a agentes com restricoes de capacidade. A ferramenta combina uma heuristica construtiva GRASP e uma metaheuristica VNS para gerar solucoes eficientes, adotando a estrategia epsilon-restrito para explorar a fronteira de Pareto entre custo total e desequilibrio de utilizacao relativa entre agentes. Na etapa decisoria, o metodo FITradeoff e empregado para incorporar informacao parcial de preferencias e reduzir o conjunto de alternativas de compromisso sem exigir a elicitacao completa de pesos. Os experimentos mostram que a integracao entre geracao de alternativas e decisao multicriterio produz uma recomendacao final consistente e reproduzivel, mantendo interpretabilidade para o decisor. O resultado e uma ferramenta compacta, de baixo custo computacional e aderente ao fluxo de apoio a decisao promovido na comunidade de Pesquisa Operacional.

## Estrutura recomendada

Uma estrutura boa para o artigo:

1. Introducao.
2. Definicao do problema de atribuicao multiobjetivo.
3. Ferramenta proposta.
4. Geracao de alternativas via GRASP/VNS e epsilon-restrito.
5. Etapa decisoria com FITradeoff.
6. Experimentos computacionais.
7. Conclusoes.

## O que tirar do relatorio antigo

- Remover a linguagem de disciplina, entregas e validacao por etapas.
- Nao manter a comparacao `soma ponderada x epsilon-restrito` como foco principal.
- Nao manter `TOPSIS` e agregacao ponderada classica como metodos centrais.
- Evitar apresentar a etapa mono-objetivo como uma secao independente muito longa.

## O que virar contribuicao

- O uso integrado de `GRASP + VNS` como motor de busca.
- A escolha por `epsilon-restrito` para gerar alternativas mais bem distribuidas.
- A combinacao com `FITradeoff` para reduzir o conjunto de alternativas e produzir uma recomendacao final.
- A interpretabilidade dos pesos viaveis e das alternativas potencialmente otimas.

## Como descrever a ferramenta

Uma descricao curta e forte:

> A ferramenta recebe a instancia do problema, gera solucoes nao-dominadas por meio de um esquema GRASP/VNS com escalarizacao epsilon-restrito, calcula atributos adicionais de robustez e, por fim, aplica o FITradeoff para apoiar a escolha final a partir de informacao parcial de preferencias.

## Decisao FITradeoff no repositorio

O pipeline novo esta em:

- `src/sbpo_pipeline.py`

Ele ja produz:

- alternativas candidatas;
- perguntas FITradeoff;
- intervalos de pesos viaveis;
- alternativa potencialmente otima escolhida;
- graficos da fronteira, cargas e espaco de pesos.

No estado atual, a sessao FITradeoff foi deixada reproduzivel com um perfil sintetico de preferencias. Isso e util para o artigo, mas pode ser trocado depois por respostas de um decisor real.

## Mensagem principal dos resultados

Para a versao SBPO, a mensagem nao deve ser "implementamos tecnicas para cumprir uma disciplina". A mensagem deve ser:

> Entre varias solucoes eficientes para o problema de atribuicao, a ferramenta proposta consegue gerar alternativas de compromisso por epsilon-restrito e selecionar uma recomendacao final por FITradeoff com baixa carga de elicitacao.
